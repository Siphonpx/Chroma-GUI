🎨 Chroma GUI 0.1.0

Systemweite Farbfilter für Windows — in Echtzeit, **ohne Injection**.

Eine Datei. Kein Overlay. Kein Eingriff in Spiele.

## ✨ Was drin ist

- Live-Regler für Vibrance, Sättigung, Kontrast, Helligkeit, Gamma, Farbtemperatur und RGB
- Profile & Presets — Competitive, FPS, Vibrant, Cinematic, Dark, Valorant
- Spielerkennung: im Vordergrund wechselt das passende Profil
- Infobereich, Autostart, Einstellungen bleiben gespeichert
- Deutsch & Englisch
- NVIDIA Digital Vibrance, wenn ein NVIDIA-Treiber da ist

## 📥 Download

Unter **Assets** die Datei `ChromaGui.exe` nehmen und starten.  
Kein .NET, keine extra DLLs.

## ⌨️ Hotkeys

| Aktion | Tasten |
| --- | --- |
| Filter ein / aus | `Strg` + `Umschalt` + `V` |
| Vibrance hoch / runter | `Strg` + `Umschalt` + `↑` / `↓` |
| Nächstes / vorheriges Profil | `Strg` + `Umschalt` + `→` / `←` |
| Fenster zeigen | `Strg` + `Umschalt` + `Pos1` |

## ⚠️ Hinweise

| Thema | Kurz |
| --- | --- |
| System | Windows 10 / 11, 64-Bit |
| Vollbild | Spiel im **randlosen Fenster** starten |
| NVIDIA | Vibrance ist damit am deutlichsten |
| Rechte | Keine Administratorrechte nötig |
